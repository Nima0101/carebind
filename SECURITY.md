# Security policy
CareBind is for synthetic association integration engineering until all frozen
evidence gates pass. It is not a clinical identity authority or medical decision
system. Signatures cannot establish physical truth or globally current status.

Do not submit patient data or secrets. Report vulnerabilities privately through
GitHub private vulnerability reporting when enabled; otherwise contact the
maintainer through their public GitHub profile to arrange a private channel before
disclosing exploit details. Do not assume private reporting is enabled locally.
No support SLA or independent security audit is claimed. The first released minor
line, when published, receives security fixes; unreleased work has no release SLA.
See docs/threat-model/ for trust assumptions and docs/verification/status.md for
known limitations. No network, telemetry or medical device access is required.
