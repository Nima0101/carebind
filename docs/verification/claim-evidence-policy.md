# Claim/evidence policy v1
Every technical claim maps to an invariant, executable check, revision and limit.
Tests establish only their modeled scope. Fuzzing is bounded exploration, not
proof of absence. Local tests are not hosted CI. A same-author reference path is
not independent human review. Offline acceptance is local knowledge, not globally
current truth. Cryptography does not verify the person wearing a tag.

No performance/adoption/clinical-benefit claims without corresponding measured
studies. No badges until inspectable checks exist. Keep failed evidence and fixed
counterexamples. Real recordings execute real commands; render transcripts only
with disclosed provenance. Report unavailable tooling as blocked, never passed.
