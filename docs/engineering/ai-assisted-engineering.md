# Human-led, AI-assisted engineering
The human selected the mission and authorized autonomous implementation. One AI
implementation owner writes the constitution before production source, checks
primary prior art, records ADRs, builds, attacks assumptions, reproduces the user
path in a clean clone, and prepares reviewable release evidence. No sub-agents.

Public artifacts expose specifications, decisions, tests and results, not private
reasoning or conversations. Same-author reference code and adversarial review
provide diverse checks, not an independent human audit. Synthetic demonstrations
cannot establish patient-safety benefit, usability in care, or adoption.

For each change: state invariant -> write counterexample/test -> implement -> run
checks -> inspect failures -> update claim/evidence map. Security changes include
malicious issuer and physical-misbinding review. Publication is blocked by any
missing mandatory gate. Status records distinguish executable evidence from
planned checks and platform claims from configured workflows.
