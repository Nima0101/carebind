# Definition of done v1
A behavior is done when specified, implemented, covered by positive and negative
checks, documented for consumers, and reflected in the threat model. The release
is done only when publication-gate.md passes on its exact source revision.
No unresolved critical-path TODOs, skipped mandatory checks or unresolved high/
critical security findings. Reproduce the README and flagship demo from a clean
clone. Preserve full command outcomes and dependencies/tool versions. Documentation
and visual claims must match actual output. Clinical deployment is out of scope.
